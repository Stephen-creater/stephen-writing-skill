# 交付检查

这是一份决策检查表，不重复讲写作方法。任何硬项不通过都要修改正文，不能用解释代替。

## A. 事实与权限

- [ ] 第一人称经历均由用户提供或确认，没有虚构实测、采访、业务结果和效率数据。
- [ ] 新闻、价格、版本、功能、强比例和引语已按需要核验；官方主张与已证实结果没有混写。
- [ ] 判断强度与证据相称，推断有明确归属。
- [ ] 外部原文的使用范围符合用户授权，广告与敏感信息没有被带入成稿。

## B. 文章合同

- [ ] 能用一句话说清目标读者读完新增的判断或动作。
- [ ] 产品升级日课通过 [实践判断检查](../examples/AI热点与产品发布/standards.md#实践判断优先)：拿掉第一人称词语后，正文仍有证据支持的取舍和可执行建议，而非只剩发布信息。
- [ ] 标题中的对象、范围、数字、实测、对比或指南承诺均被正文兑现。
- [ ] 标题或第一节保留了让这篇文章今天值得写的现实锚点。
- [ ] 用户本次指定的篇幅、覆盖率、格式和交付位置均满足。

## C. 主路径

- [ ] 全文只有一条可复述的因果链、使用导航、决策清单、对象流程或体验链。
- [ ] 每节回答的仍是标题里的问题，没有因为「相关」切换到另一个读者问题。
- [ ] 相邻段落共享具体对象或问题，后一段使用了前一段刚建立的信息。
- [ ] 流程中的文件、字段、图片和产物按实际出现顺序解释，没有未来对象提前出现。
- [ ] 数字型标题、章节、判断项和结尾问题一一对应。

## D. 读者理解

- [ ] 开头零句或一句进入核心冲突，没有重复标题和背景热身。
- [ ] 必要术语首次出现时已说明当前作用，没有用未解释的新术语解释旧术语。
- [ ] 小白读者不需要为案例临时学习非必要平台、代码或工具背景。
- [ ] 图片缺失后，输入、动作、输出和变化仍完整；「这个」「那个」都有唯一先行词。
- [ ] 第一人称承担作者判断，客观机制由对象承担，读者场景使用「你」，没有机械换代词。

## E. 信息密度

- [ ] 已按「问题 → 章节 → 段落 → 句子」顺序做删除测试。
- [ ] 每段至少新增事实、因果、区别、证据、边界、选择或动作中的一项。
- [ ] 没有用机制、Demo、类比和行业意义从不同层级重复同一个结论。
- [ ] 一个案例已经成立时，没有保留第二个同类案例或案例后的抽象复述。
- [ ] 外部补充只保留会改变理解、使用、付费或行动的信息。
- [ ] 来源目录、人物履历、直播现场、研究过程、销售入口和转述外壳已按必要性删除。

## F. 中文与声音

- [ ] 像真实实践者在说话，不是机构通稿、翻译稿或资料汇编。
- [ ] 小标题准确服务判断或导航，没有为了统一格式硬改成同一种句式。
- [ ] 没有「是 X，不是 Y」等翻案句，没有空转连接词和廉价震惊词。
- [ ] 正文默认无双引号；必要标示只用「」；没有用破折号制造语气。
- [ ] 已运行 `scripts/check_style.py` 并通过。

## G. 结尾与成品

- [ ] 结尾承接最后一段，只完成判断、选择、边界或未来推进中的一项。
- [ ] Aha moment 由前文推导，不是临时拔高；正文已闭环时没有重复总结。
- [ ] 正文独立完整，没有任务说明、模型自述、研究笔记和未处理格式残留。
- [ ] 只交付用户要求的媒介和数量，未确认初稿没有进入案例库或外部发布。

## 覆盖率口径

授权原文整合任务使用连续 30 字匹配计算。用户明确指定数字时按本次数字验收；未指定时以 80% 为正常目标、70% 为最低线。报告实际数字和口径，不用主观感觉代替计算。
