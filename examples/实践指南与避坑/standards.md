# 实践指南与避坑

## 读者任务

让读者在一个明确决策时点知道该检查什么、怎样操作、什么结果算过关。

## 常用路径

- 单一流程：原理 → 输入 → 处理 → 产物 → 复用。
- 多标准决策：N 个独立标准共同决定是否行动。
- 团队实践：现实变化 → 协作机制 → 可执行动作 → 质量边界。

## 本类独有检查

- 标题写清对象、动作或决策时点，不把所有企业 AI 问题装进一篇文章。
- 流程对象按实际出现顺序解释，后一步的文件和字段不提前展开。
- 数字标题、章节、判断项和结尾问题完全对应，不为凑数保留一条。
- 决策清单每节只用一个主要案例，案例只证明当前标准。
- 团队项目只保留证明方法所需的人数、周期、场景、过程和成果；删除履历、服务介绍与销售入口。
- 原则至少落到原因、动作和验收中的两项，不能只喊口号。
