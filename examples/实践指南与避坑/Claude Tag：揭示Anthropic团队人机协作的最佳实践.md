# Claude Tag：揭示Anthropic团队人机协作的最佳实践

## 一、AI协作进入联机模式

过去，使用 AI 一直是一种「单机」体验，一个人和 Agent 协作，完成个人任务。

而现在新的模式是，人类和 Agent 可以在同一个工作空间里协作，服务于一个团队共享的目标。工作开始更像一场「多人联机游戏」，由人类团队制定策略， Agent 来执行。

而实现这一转变的便是 Anthropic 新产品 Claude Tag，一种让 Claude 进驻 Slack 等团队协作工具、像团队成员一样被 @ 和被指派的形态。

官网博客介绍：[https://claude.com/blog/building-effective-human-agent-teams](https://claude.com/blog/building-effective-human-agent-teams)

## 二、Agent先看见团队，再明确分工

一般来说，AI 能读取到的，只有「写下来的东西」。AI 主要通过文档、工作群聊天记录、会议纪要、代码等可检索的信息来理解团队。

所以很多人类团队口头达成共识的默认信息，其实 AI 完全不清楚。比如，我们开会时说过的话、员工之间的私聊、某位老员工脑子里的业务背景，AI 是看不到的。如果项目已经暂停了，但这个信息只出现在几个人的私聊里，AI 就可能继续按照旧计划推进。

Anthropic 的做法，是让重要信息尽量同步到公开的工作空间里。项目进展、任务负责人、关键决定，都应该记录在团队能够访问和检索的地方。以前我们写文档，可能只是为了方便团队查阅。现在，文档还承担了另一个作用，给 AI 同事提供工作背景。

这一招的精妙在于它同时解决了两个问题：1.扩大了 Agent 和人能拿到的上下文；2.消除了「逐项分享」带来的决策疲劳。

如此，人机团队就能共享一份花名册、一套产物、一个工作空间。在这之上，Agent 各有分工。比如，一个 Agent 做某项目的数据分析，另一个执行设计规范，第三个负责研究综合。

## 三、北极星决定方向

当 Agent 已经拥有丰富上下文、清晰角色和对应工具，下一步是让它主动发现问题。

Anthropic区分了两类 Agent，一类只是「完成被指派的任务」，另一类，也是最重要的一类，会主动提出新项目和新工作流。

后者的最佳实践里，除了要求团队具备丰富的上下文和清晰的角色外，还会有一条额外的指引，也就是北极星。

北极星负责帮团队判断「哪些任务和工作流才是对的」。注意，北极星永远由人类设定，并扎根于公司的使命与业务目标。北极星一旦被清晰地写下来，人类需要把它分享给团队里的 Agent。然后，人类挑选哪些 Agent 应当主动提议新工作流。

文章中举了一个例子。一个团队把「让新用户更容易上手我们的产品」定成北极星，AI 发现产品的报错提示写得太难懂，很容易把用户劝退。于是它主动提出文案修改建议，新的提示上线以后，下一周的新用户上手成功率出现了明显的提升。

## 四、AI会放大团队原本的样子

上面这几条经验其实并不新颖，早在 AI 出现之前就存在了。好的团队要有强有力的北极星、清晰的角色、扎实的文档、共享的质量标准、从错误中学习的空间。

如果没有合理的机制建设，AI 不会自动让团队变强，甚至会造成挤压，最终带来混乱。上下文涣散的团队，接入 Agent 后只会更涣散；角色定位混乱的团队，Agent 只会复制混乱；没有验证文化的团队，Agent 的错误会以更快的速度规模化。

因此，从这波 Agent 红利里拿到最多的团队，也是那些最有意识地去践行这些基本功的团队。

对正在押注 AI Agent 的组织来说，眼下需要回头把自己团队的上下文、角色、目标与质量标准这四件旧事，认认真真地重做一遍。

AI 不会拯救一个混乱的团队，它只会把团队原本的样子无限放大。
