# 一个skill，蒸馏任意写作风格

## 一、把写作风格拆成六层

这个 skill 最核心的设计，是基于语言学的研究方法，用量化统计和深度分析的方式，把写作风格总结成可复制的规则，AI 写作的时候就能逐层对照。

它的底层假设是，写作风格其实是好几个相互独立、又彼此咬合的文本层次叠加的，因此需要把每一层单独拆开分析。

L1 是最小单位，语言层面本身的统计，比如作者爱用哪些词、句子多长、爱不爱用感叹号等等。
L2 则是文章的「骨架」，怎么开头、递进、收尾。
L3 到 L5 是思维层面，选题出发点，作者站在什么角度写作，思维框架是什么，认知是什么。
L6 是最后的配图和排版。不过，如果你给的素材中都没有配图、也没有样式，那么这一层会跳过蒸馏。

## 二、3步蒸馏出Writing DNA

第一步是攒素材。

蒸馏skill的产出质量，上限是被素材锁死的。你给 agent 喂二流素材，蒸馏出来的产物当然也不会比这个更好。素材太少了，能分析的规律有限，效果也会很差。

数量：至少 20 篇这个作者的完整文章。30 篇才算进了理想区间，连那些低频的小习惯都能采到。但大部分场景下，其实也不需要特别多的素材。如果文章数量太多导致风格不够统一，最后蒸馏出来的效果也不一定更好。

长度：单篇最好超过 1000 字。太短的撑不起结构层和认知层的分析。
格式：`.md` 或者`.txt` 纯文本就行。
完整：要全文，不要摘要、不要片段。

体裁统一：尽量选同一类体裁的文章放在一起蒸。一个人写日记和写论文的风格会差得很远，混在一起蒸馏，模型会取中间值，哪种都学不到位。如果这个作者有好几种明显不同的写法，最好是在蒸馏时就让 agent 按照不同的体裁蒸馏，效果会好很多。

第二步是蒸馏。

素材备好之后，后面就特别简单了。你只需要对 agent 说一句话：「用 [github.com/larashero3-dotcom/writing-dna-skill](https://github.com/larashero3-dotcom/writing-dna-skill) 蒸馏这个目录里的所有文章」。

等 agent 蒸馏完，你会获得 5 份 DNA 文档加一个 `_meta` 文件夹。5 份 DNA 文档里最重要的是 `Writing-DNA.md`，它是对整个写作风格的总结。如果素材里没有配图，也没有格式，就不会有视觉风格指南这个文件。

第三步是复用蒸馏文件。

蒸馏后，AI 不是直接就能写出这个风格。相反，每次写作前，都必须让 agent 重读所有风格文档，还要读几篇相关的原材料，才能最好地复现写作风格。

仓库当前的明确规则是，每次写作前读 5 篇与当前题材和体裁最接近的原文。

再进阶一点，你可以把这份 DNA 直接固化成一个独立的写作 Skill，固化之后以后连文档都不用手动喂了，直接调用就能出稿。

## 三、蒸馏调整注意力，微调改变权重

举个例子，大模型在预训练时肯定读过《红楼梦》，但你直接让它模仿红楼梦的风格写，它只能从几十亿参数里模糊调取一点残影，因为红楼梦的文本已经和其他万亿 token 的训练数据混在一起了，信号被稀释得差不多了。

但如果你把十几万字的红楼梦原文摆进上下文，再把提炼出来的风格规则放在最前面，模型的注意力就被锚定在这些具体内容上了。它生成每一个字的时候都在看这些规则，输出自然更贴合红楼梦本身的风格。

很多人尝试过用微调来模仿写作风格，但最后效果很差，因为微调的效果不一定好。拿几十篇文章做 SFT（监督微调），这几十万字相对于模型预训练见过的万亿 token，信号太弱了，权重几乎没怎么偏移。训完之后推理时又没有任何显性提醒，模型又回到那个巨大的参数空间里随机漫步，风格当然也会飘忽不定。

## 四、它能复刻怎么写，复刻不了想什么

这是这个 skill 最重要的边界。

它能高保真复刻一个人的声音和结构，也就是那个「容器」。但它给不了作者此刻的认知，这些东西不在历史语料里，它当然抓不到。

如果你想用蒸出来的风格写一篇有深度、有见解的新文章，光有写作蒸馏的 Writing DNA 文件还远远不够，你还得给 agent 足够多的上下文，自己的感受和认知，或者让 agent 检索足够多的优质信息。

一个基本的写作流程是这样的：有了想写的话题之后，自己先获取所有相关的信息、不断和 agent 交流得出新的认知，然后把所有的内容都放进同一个上下文空间里。

有些人打字很慢，如果嫌麻烦，不妨试试口喷转文字，比如typeless（第一个月免费）、豆包输入法等等，能够所说即所得，最后让 agent 读以上所有内容，并按照蒸馏出来的风格写作。

最后，如果你希望使用别人的文案风格，帮助自己更好的写作，那么不妨试试这个skill，也许会给你不一样的惊喜。GitHub仓库地址：[https://github.com/larashero3-dotcom/writing-dna-skill](https://github.com/larashero3-dotcom/writing-dna-skill)
