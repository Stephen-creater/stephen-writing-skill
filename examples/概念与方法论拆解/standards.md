# 概念与方法论拆解

读者想知道：一个概念为什么成立，它和相近的概念有什么区别，弄懂之后自己的判断会有什么变化。

## 常见写法

最少的几个概念 → 最朴素的过程或现象 → 出现了什么问题 → 靠什么解决 → 推到相近的概念或更高一层的结论 → 适用边界。

每一节都要回答上一节留下的问题。来源的目录只是素材，不能直接当文章目录。

## 容易出错的地方

- 必要的术语，先说它在这个过程里干什么，再把它们串成一个完整过程。
- 一组相关概念尽量用同一个案例或同一个比喻讲完，不要每个术语换一套。
- 用一句话或一个小标题就能让人接受的前提，不要展开成一整节。
- 标题的方向改了，旧标题需要的概念、建议、案例都要重新检查还该不该留。
- 深度来自把原因讲到底，不来自公式和专业词的数量。
