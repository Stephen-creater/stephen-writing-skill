# REA 刷屏了，但它不值得你花太多时间

最近 REA 刷屏了。它的全称是 Reverse Engineer Anything，逆向一切：装进 Claude Code、Codex 之后，Agent 能去拆一个没有源码的软件，写代码完整复刻整个软件的功能。

很多自媒体跟着喊：商业软件要完蛋了，闭源软件都能被 AI 逆向成开源的。

但我的判断是，REA 不值得你花时间。

## 一、REA 没有发明新的逆向技术

REA 自己不会逆向。要用它拆软件，你得先在电脑上装好这类逆向软件，REA 做的只是把它们的功能整理好，交给 Agent 去调用。

而逆向这门手艺有几十年历史，专业的逆向软件也早就有。最老牌的 IDA 从上世纪 90 年代就开始卖了，9 月底，IDA 的开发商发布了官方插件，免费开源，装上之后 Agent可以直接使用。

## 二、刷屏的成绩，大多不是 REA 做出来的

逆向软件官方就能接 Agent，所以网上那些 AI 逆向的成绩，不一定跟 REA 有关。

最出圈的一个，是一位国外的逆向工程师用一群 Agent，把 2009 年的《使命召唤：现代战争 2》还原成了源代码。他干了 3 个月，99% 的函数都还原了出来，游戏能流畅运行。

这个案例常被和 REA 放在一起转，可他全程用的是 IDA 的官方插件，没用 REA。

还有人说一批对标 Adobe 的软件是 AI 逆向出来的。做这批软件的开发者自己澄清过：他们没拆 Adobe 的程序代码，是照着软件的功能和用法，让 AI 从头重写的，团队里连拆代码的逆向软件都禁用，怕吃官司。照着成品的样子仿写，宽泛地说也算逆向，但这条路用不上 REA。

## 三、REA 的星标有刷量嫌疑

成绩不是它的，热度也有水分。在 GitHub 上，Star 相当于收藏，Watch 是订阅项目的更新。截至 10 月 13 日，REA 有 17 万个 Star，订阅更新的只有 565 人，约千分之三。按国外一位开发者的统计，一个被大量收藏的普通项目，这个比例在 2% 左右。

他还盯着 REA 连续测过：将近两天里 Star 涨了 4.7 万，平均每小时 1000 多个，连半夜都没慢下来，而真人点收藏，到了夜里是会变少的。

## 四、如何看待 REA

第一，REA 的热度很快就会退。你不需要关注它，直接屏蔽 REA 这个关键词，什么都不会错过。

第二，「商业软件要完蛋」站不住。开源软件的源码本来就谁都能看，卖开源软件服务的公司照样赚钱，企业买的是有人维护、有人兜底。绝大多数人也根本没有逆向商业软件的需求，真有这个能力和需求的人，早就默默去干了。

第三，真正会留下来的，是 Agent 接管专业软件这件事。那位还原《使命召唤》的工程师，经历就说明了 Agent 怎么才能把专业的活干好。

第一个月，他让 3 个 Agent 写、1 个 Agent 审，游戏能启动、能进地图，可代码逻辑大量是错的，最后整批扔掉。后来他写了个脚本，把 Agent 还原的每个函数用原版的编译器重新编译，和原版逐字节对比，对上了才算过。有了这个自动判对错的检查，连便宜的小模型都能干好活。

所以，对自己有期待的朋友，不用去装 REA。更值得想的是：你行业里用的专业软件，哪一个会最先被 Agent 接手，Agent 干完的结果又该怎么自动检查。
