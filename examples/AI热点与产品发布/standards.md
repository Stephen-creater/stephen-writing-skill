# AI 热点与产品发布

读者想知道：这次发布跟我有什么关系，值不值得试，怎么试。发布事实只是判断的背景。

## 常见写法

- **当天解读**：发生了什么 → 它能做什么 → 我的判断。能做什么这一段，有 Stephen 的真实测试就写测试；没有就只选一个作者的完整案例，按输入、结果写完。判断一两句就够，融进正文或结尾，不单独开一节讲「怎么试」。
- **产品速览**：入口 → 核心能力 → 功能 → 价格。小标题直接写「3 种入口」「免费版和付费版」。
- **协议或标准**：一句话定义加一个类比 → 怎么工作 → 现在能用到什么程度、有什么限制。
- **单个新功能**：发现了什么 → 官方怎么说 → 用在什么场景 → 我的判断 → 隐私或限制。千字以内可以不分节。

## 容易出错的地方

- 只列功能、转述发布会，删掉「我」之后只剩功能清单。这类文章要有自己的判断。
- 标题或第一节没点明是哪个产品、什么时候发的。
- 参数、Demo、竞品，只在影响读者选择时才留。机制讲清后再放 Demo 重演一遍，就是重复。
- 配图只留能证明效果的 1 到 2 张，最好是一张输入、一张输出。教程不受这个限制。
- 可以在结尾点名直接竞品，形成一个明确的格局判断，但不要泛泛写行业未来。
- Stephen 明确只要快讯或纯速览时，照要求写，不硬加个人观点。
