# AI 热点与产品发布

## 读者任务

让读者迅速明白发生了什么、它怎样工作、现在能否使用，以及这次变化意味着什么。

## 常用路径

- 单功能热点：发现对象 → 官方定义 → 使用场景 → 核心判断 → 隐私或边界。
- 产品速览：入口 → 核心能力 → 功能地图 → 生态 → 价格。
- 协议或标准：是什么 → 怎么工作 → 当前开放范围与限制。

只选一种主路径。千字短文可以不用小标题；速览可以用导航型小标题，不强制下观点。

## 本类独有检查

- 标题或第一节明确发布对象和现实时间点。
- 参数、Demo 和竞品只在改变使用或判断时保留。
- 标题没有「实测」「对比」「完全指南」时，不写对应支线。
- 官方 Demo 只重演机制时删除；定义、机制和边界已经完整即可。
- 普通产品文落到作者怎么选或怎么用；行业发布可以点名直接竞品，推进一层格局后结束。
