# ChatGPT & Codex 新功能--Computer History

刚刚，在 ChatGPT 的设置里发现了一个挺容易被忽略的新功能，叫做 Computer History，计算机历史记录。

看到名字的时候，很容易以为它和浏览器的历史记录差不多，但仔细研究会发现，很不一样。

OpenAI官方介绍：[https://learn.chatgpt.com/docs/customization/computer-history](https://learn.chatgpt.com/docs/customization/computer-history)

官方的表述是，只要打开，就可以记录你在应用和网站上的活动，把它转化为记忆和时间线，供 ChatGPT 和 Codex 参考。你还可以询问近期的工作问题，从上次中断的地方继续工作，并将重复的工作流程转化为 Skill 或自动化操作。

Computer History 会读取点击、输入、快捷键、应用切换，以及 macOS 辅助功能能看到的文字和上下文。说白了，它记的是你在什么软件里，做了什么动作，当时处理的又是什么事情。

比如，你休假了几天，回来后可以打开 Codex，询问最近的电脑使用记录，「我上次停止工作的地方是哪里？」这就相当于一种断点续传。如果没有 Computer History，它就不能告诉你前序工作是什么。

再比如，它可以帮助你查找近期使用过的文件。你通过计算机打开了一份文件，但是想不起名字，就可以问它，「那份规划文件的名字是什么？」它会通过电脑的历史记录告诉你，你曾经在 Google Docs 上打开并使用了哪一个文档。

同时，它还能够复刻你的工作流程。比如你告诉它，「我刚刚把这个视频上传了，下次把这个操作复刻一下。」它就会帮你形成一个 `SKILL.md` 文档，下次可以直接调用。

以前 AI 学的是书本知识和互联网知识，现在它学的是我们在电脑上的操作。它的学习对象改变了，变成了学习你的行为和动作。相当于这个 Agent 在默默观察你的行为模式。

这和先前上线的新功能——[Record & Replay](https://learn.chatgpt.com/docs/extend/record-and-replay) 有明显区别。Record & Replay 需要我先意识到这套动作有用，再专门录下来让它复刻。Computer History 是在我允许的范围里持续记录。可能我自己都没有发现某件事情已经做了很多遍，它先发现了。

以前都是我们主动告诉 Agent，「你来帮我做某件事情。」未来则可能变成 Agent 主动问你，「这件事情你周三和周五已经连续做了三次，要不要我把它做成一个 Skill，帮你定期执行？」

最后说下隐私。

打开 ChatGPT，点击左下角的设置，在「计算机历史记录」这里点击打开，然后授予相应权限。你也可以排除指定的应用或指定的网页，被排除的内容不会记录到计算机使用历史中。

原始事件最长在 Mac 上保留 48 小时，然后会交给临时 Codex 会话处理。OpenAI 表示，处理完成后不会保留这些事件，也不会拿去训练模型。以及，整理出来的记忆会以 Markdown 文件保存在本地，直到我手动删除，而且这些文件没有额外加密。

从 Chat、Memory、Computer Use，到 Skill、Automation 和今天的 Computer History，OpenAI 想做的已经很明显了：既记住你说过什么，也记住你每天怎么工作，最后做成一个能够替人干活的，真正意义上的个人操作系统os。
